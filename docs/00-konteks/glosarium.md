# 📖 Glosarium Istilah & Kamus Domain

Dokumen ini memuat definisi istilah teknis dan terminologi domain sekolah yang digunakan di seluruh aplikasi.

---

## 1. Domain Presensi & Kehadiran

| Istilah | Definisi |
| :--- | :--- |
| **Kiosk Scan** | Mode antarmuka layar penuh di gerbang sekolah yang menerima input pemindaian barcode/kartu siswa secara mandiri tanpa memerlukan interaksi keyboard/mouse manual. |
| **Scan Masuk (In)** | Pemindaian kehadiran pagi sebelum batas toleransi jam masuk dimulai. |
| **Scan Pulang (Out)** | Pemindaian kehadiran sore saat jam kepulangan sekolah telah dibuka. |
| **Batas Jam Masuk** | Waktu cut-off jam masuk (misal `06:45:00`). Melebihi jam ini, status presensi siswa dicatat sebagai **Terlambat**. |
| **Auto-Alpa** | Proses otomatis oleh scheduler yang menandai siswa berstatus *Alpa* apabila hingga jam cut-off kepulangan siswa belum memiliki catatan presensi dan tidak mengajukan izin/sakit. |
| **Presensi Sholat Dhuhur** | Pencatatan kehadiran ibadah sholat dhuhur berjamaah bagi siswa muslim, dapat diisi via kiosk khusus atau diinput langsung oleh wali kelas. |
| **Presensi Sholat Jumat** | Opsi presensi sholat jumat berjamaah yang dapat diaktifkan/dinonaktifkan melalui menu pengaturan presensi admin. |

## 2. Domain Bimbingan Siswa (Guru Wali & BK)

| Istilah | Definisi |
| :--- | :--- |
| **Guru Wali** | Guru yang bertugas sebagai pembimbing dan pendamping karakter bagi sekelompok siswa tertentu (mirip konsep wali asuh / mentor). |
| **Jurnal Guru Wali** | Catatan kegiatan harian atau mingguan yang mendokumentasikan interaksi, pembiasaan karakter, dan observasi perkembangan siswa asuh. |
| **Badge Karakter** | Penghargaan simbolik digital (seperti Kejujuran, Kedisiplinan, Gotong Royong) yang disematkan oleh guru wali kepada profil siswa. |
| **SPIKAP** | *Sistem Pengaduan dan Konseling Terpadu*: Platform penanganan laporan pelanggaran, perundungan (*bullying*), keluhan sarana, dan mediasi BK. |
| **Rujukan BK** | Rekomendasi kasus dari guru kelas/wali kelas kepada guru Bimbingan Konseling (BK) untuk penanganan lebih lanjut yang membutuhkan sesi privat. |

## 3. Domain Perpustakaan & Akademik

| Istilah | Definisi |
| :--- | :--- |
| **Eksemplar Buku** | Salinan fisik (*physical copy*) dari sebuah judul buku. Satu judul buku dapat memiliki banyak eksemplar dengan kode barcode/nomor induk unik. |
| **Klasifikasi DDC** | *Dewey Decimal Classification*: Standar internasional pengelompokan subjek koleksi buku (misal: 000 Karya Umum, 500 Sains, dll.). |
| **Sirkulasi** | Proses operasional peminjaman, perpanjangan, pengembalian, serta pencatatan denda buku perpustakaan. |
| **CBT Profile** | Kredensial akun ujian siswa (username/password/nomor peserta) yang disinkronkan untuk pelaksanaan asesmen berbasis komputer. |
